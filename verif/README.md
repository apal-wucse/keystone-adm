# ADM（Protected Sharing on Keystone）の形式検証：まとめ

対象：論文3章の設計と、その実装（SM、SDK のライブラリ、ランタイム）。保護設定は `DEFAULT_NOPERM` に限る。
詳細は `verif/MODEL.pdf`、証明図は `verif/PROOF.pdf`。

## 1. 検証した性質

| 区分 | 内容 |
|---|---|
| A1〜A9 アクセス制御 | ADM に触れられるのは実行中の hart だけ。ホストの権限はエンクレーブが明示した共有を超えない。破棄時は機密を消してから返す |
| B1〜B8 検証の強制 | ホストが書けた後は必ず検証を経て再開する。検証中は SM 以外が触れない。検証関数は健全（B6）かつ安全（B7） |
| C1〜C5 PMP 構成 | ADM は他の保護領域と重ならない。エントリの優先度と実効範囲は指定どおり。失敗時に途中状態を残さない |
| D1〜D4 ライフサイクル | SBI の発行元の制約、状態の整合、任意のインターリーブでの頑健性 |
| E1・E2 | 機密性と完全性（上の性質から導く） |

## 2. 手法と結果

| 手法 | 対象 | 結果 | 保証の範囲 |
|---|---|---|---|
| TLA+（TLC） | 設計モデル | 反例なし。到達可能性と変異試験で空虚でないことを確認 | hart 3・エンクレーブ 2 まで |
| Rocq | 設計モデル | A・B・C1・C2・D1・D2・E を証明。公理なし | hart 数・エンクレーブ数・ADM の内容によらない |
| 証明図 | Rocq の証明 | 428 図を自然演繹で生成し、すべて Rocq で再検査 | 領域配置の帰納法の組み立ては元の証明に頼る |
| TLA+（TLC） | 実装モデル（ロック・IPI・HSM を含む） | 修正前は17項目すべてに反例。修正後はすべて成立 | hart 3・エンクレーブ 1、hart 2・エンクレーブ 2 |
| CBMC | 検証関数（B6・B7） | 範囲外を読まない、桁あふれしない、W1〜W12 が成立 | B7 は領域数16、B6 は6まで |
| CBMC | エンクレーブ側ライブラリ | ADM の外に書かない、他の領域を壊さない、WF を保つ | 領域数6まで |
| CBMC | PMP 領域の割当（C1・C2・C3・C5） | 全項目成立 | 操作 8 回まで |
| CBMC | SBI 引数のアドレス（H8） | SM は呼び出し元の EPM の外を読み書きしない | 表の添字ごとに検査 |
| QEMU | #1・#7・#13・#15・#16 | 修正前の SM で再現し、修正後は起きないことを確認 | 実行による確認 |

## 3. 見つけて修正した問題

| # | 内容 | 影響 |
|---|---|---|
| 1 | 検証に失敗したエンクレーブが破棄されない | 資源が残る |
| 2〜4 | 検証関数の漏れ（UID の重複、型の未照合、桁あふれ） | 偽の `size` でエンクレーブが ADM の外を読み書きする |
| 5 | 古いメタデータが検証に使われる | 渡していない領域が検証を通る |
| 6・11・12 | 引数・状態の検査が状態変更より後、二重 destroy | 2つの hart で同時実行、ADM の露出 |
| 7 | hart を再起動すると PMP が設定し直されない | ホストが実行中の ADM を読み書きできる |
| 13 | 停止と再開の競合（新規） | 再開後もホストが RW を持つ |
| 14 | PMP エントリが OS 領域と共有される | 優先度と実効範囲が崩れる |
| 15 | 封印鍵 SBI が引数のアドレスを確かめない | EPM の外への書き込み |
| 16 | ライブラリの領域削除とメタデータの大きさの誤り | ADM の外への書き込み、正当な ADM が検証で落ちる |

#8〜#10 は論文と実装の違いの記録で、修正の対象ではない。

## 4. 検証していないもの

- EPM のハッシュ計算（`validate_and_hash_enclave`）と複写のアセンブリ（`mprv.S`）
- ADM 内のアロケータ（`adm_alloc.c`）
- `DEFAULT_READ` の構成
- #15 の読み出し側の QEMU での実行（書き込み側だけ確認）
- 検証関数とライブラリの、上限を超える領域数

## 5. 再現方法（`verif/` で実行）

| コマンド | 内容 |
|---|---|
| `make check` / `make reach` | 設計モデルの検査と到達可能性 |
| `make prove` | Rocq の証明 |
| `make prove-figures` | 証明図の Rocq による再検査 |
| `make check-impl` | 実装モデル（修正版） |
| `make cbmc` | CBMC の全手順（約83分） |
| `qemu/run-tests.sh` ほか | QEMU での確認 |
